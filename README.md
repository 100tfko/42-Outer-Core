# 42-Outer-Core

This repository serves as an index and navigation point for my 42 Outer Core projects.

The projects themselves are kept in their own repositories. This repository organizes them into a structured tree, providing a simple way to navigate through the different parts of the Outer Core.

## About 42

42 is a project-based, peer-to-peer programming school. Instead of following a traditional lecture-based curriculum, students learn by working on projects, researching solutions, and collaborating with other students.

After the Common Core, the curriculum can be extended through the Outer Core, allowing students to explore additional technologies, programming paradigms, and areas of software development.

As with the Common Core, projects are based on practical work and peer-to-peer evaluation, encouraging students to learn independently and through collaboration.
